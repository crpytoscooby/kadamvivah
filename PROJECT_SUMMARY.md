# KadamVivah - Project Summary

## Overview

KadamVivah is a complete frontend application for a free Maratha matrimony service. The project is production-ready and includes all requested features.

## ✅ Completed Features

### Authentication & Access Control
- Login page (email + password only)
- Comprehensive registration form with validation
- Protected routes for authenticated users
- Admin role-based access control
- Mock authentication for development

### Core Pages
- Home with hero, CTA, blocked preview, and Nitin Kadam thank you section
- Login and Register with full validation
- Profiles listing with filters and pagination (protected)
- Profile detail with carousel and full info (protected)
- Admin dashboard with CRUD operations (admin only)
- About, Contact, Privacy, Terms pages

### Design System
- Brand colors (Deep Red #C8102E)
- Typography (Inter + Noto Sans Devanagari)
- Mobile-first responsive design
- Accessible and semantic HTML

### Components
- Navbar with authentication states
- Footer with bilingual content
- ProfileCard, ProtectedRoute, Toast
- Form validation and error handling

### Data & API
- Mock profiles and users in JSON
- Axios API wrapper ready for backend
- Comprehensive integration documentation

## 🚀 Quick Start

pnpm install
pnpm run dev
